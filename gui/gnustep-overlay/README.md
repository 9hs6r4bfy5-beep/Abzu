# gui/gnustep-overlay — our deltas on GNUstep core

Pinned upstream versions (verified against gnustep.org releases):

| component | version | role |
|---|---|---|
| gnustep-make | 2.9.2 | build system |
| gnustep-base | 1.31.1 | Foundation (NS* classes) |
| gnustep-gui  | 0.32.0  | AppKit equivalent |
| gnustep-back | 0.32.0  | backend (X11 for bring-up; native CGS target) |
| GWorkspace   | 1.1.0   | desktop shell |

Overlay patches (`patches/`, applied by `../build-gui.sh` via
`apply_overlay_patches()` -- `git apply -p1`, fail-closed, against the
extracted gnustep-gui-0.32.0 tree; the Nix `gui-core` derivation does NOT
postPatch them -- it stages theme/binaries only, see build/derivations/
gnustep.nix header for the contract):

- `0001-font-smoothing.patch` — map `-GAFontAntialiasing` defaults so text
  matches Aqua-style subpixel rendering out of the box. (Source/NSFont.m)
- `0002-theme-search-path.patch` — add `/System/Library/Themes` and
  `/Library/Themes/AbzuAqua.theme` to theme lookup before user dirs.
  (Source/GSTheme.m)
- `0003-caustics-compositor.patch` — hook `NSView` background draw to blit
  the animated caustic layer from AbzuAqua.theme when `Caustics.Enabled`.
  (Source/NSView.m)
- `0004-doas-auth.patch` — add an NSWorkspace authorization helper routing
  privileged GNUstep operations through `doas(1)` instead of sudo askpass
  (security pillar). NOTE: upstream gnustep-gui 0.32.0 has no sudo/askpass
  call site to replace (the previously claimed GSSystemRootAction.m does not
  exist), so this patch ADDS `-abzuAuthorizeAndRunAsRoot:` to
  Source/NSWorkspace.m as Abzu-specific glue for GWorkspace/AbzuShell
  callers; smoke-test on first overlay build.

All four are git-format diffs regenerated byte-for-byte against the real
gnustep-gui-0.32.0 tarball (validated with `git apply --check -p1` on
2026-10-10); upstreaming is tracked per-patch in ../../docs/ROADMAP.md.
